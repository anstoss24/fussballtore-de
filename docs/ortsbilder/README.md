## Regeln für neue Ortsbilder

- Unser Tor muss erkennbar sein (Shop-Produktfoto als Vorlage), schräg von vorne, ganz im Bild.
- Der Ort muss eindeutig sein: Spielplatz mit Spielgeräten, Schule mit Schulgebäude und Basketball-Tor, Kommune mit Wohnblocks/Laterne/Bank statt Vereinsplatz.
- Keine Menschen, keine Schrift, kein Produktfoto-Ersatz. Immer „Symbolbild“.
